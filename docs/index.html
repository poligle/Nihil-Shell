How Nilo works

The phone and the watch, as decks

NIHIL Launcher on Android opens this computer's apps, plays its music and is its trackpad, and Vector carries a text, a picture or a file either way. The watch keeps its music and its volume on the bezel.

Install

Each machine keeps what is its own in /etc/nixos; NIHIL comes from here, and updates never touch what is yours.

With the installer

The ISO is in Releases. Write it to a USB stick and boot it: it asks a few questions, finds the screens and the GPU, and makes room next to Windows or takes a whole disk.

Releases

On a NixOS you already have

Clone it, give the machine its flake and rebuild. Then one command keeps it current.

nihil update     # the latest NIHIL, then rebuild
nihil rebuild    # your changes to /etc/nixos
The whole guide

Made of greys

Greys for hierarchy, dots for display, red only to interrupt. One file holds the tokens, and GTK, the terminal, the viewers, the compositor, the lock screen, the boot splash and the shell are made from it.

  • Void#000000
  • Surface#0E0E0E
  • Raised#1A1A1A
  • Line#2A2A2A
  • Off#333333
  • Muted#7A7A7A
  • Dim#A3A3A3
  • Ink#F2F2F2
  • Signal#D71921
